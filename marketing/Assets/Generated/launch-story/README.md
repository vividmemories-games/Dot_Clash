## Where to use

| Platform | Format | How |
|----------|--------|-----|
| **WhatsApp Status** | 9:16 | Upload panels 1→7 in order; pin panel 6 (live announcement) for 24h |
| **Instagram / Facebook Stories** | 9:16 | Same sequence; add link sticker on panel 6 |
| **Reels / Shorts** | 9:16 | 2–3 sec per panel, soft fade; end on panel 6 with store CTA |
| **Facebook feed** | Crop to 4:5 or 1:1 | Use panel 6 as hero post; panels 1–5 as comment thread or album |
